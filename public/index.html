How Sanjaya works

  1. 1
    Detect. Tested rules parse every line and flag brute force, port scans, web exploits, privilege escalation and backdoor accounts. All scores come from code, never from the model.
  2. 2
    Investigate. A Gemini agent reads the evidence through tools, correlates the kill chain, maps it to MITRE ATT&CK and explains it in plain English. Planted instructions in the logs are flagged, never followed.
  3. 3
    Approve. Fixes come only from a fixed playbook with safe command templates. Nothing runs automatically: you approve or reject each step, and every decision goes into an exportable runbook and audit trail.

Defensive use only. Demo data uses documentation IP ranges (RFC 5737). Built with Gemini on Google Cloud Run.
